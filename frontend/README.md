# DispatchIQ

Frontend prototype for a regional appliance repair dispatch workspace, built with Flutter.

## Run locally

1. Install the Flutter SDK and add it to your system `PATH`.
2. From this folder, run `flutter pub get`.
3. Run `flutter run` for a connected device, emulator, or Chrome.

The current frontend uses local mock data and Material 3 components. Firebase, maps, authentication, and live technician data can be connected after the dispatch workflow and visual direction are approved.
